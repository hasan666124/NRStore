# 📱 NR Store

**NR Store** is a modern Mini App Store designed for browsing, discovering, and downloading authorized Android APK applications.

The project is designed to be mobile-friendly and will include both a **User App** and an **Admin Panel**.

---

## 🚀 Project Goals

NR Store aims to provide a clean, simple, and modern platform where users can:

* 🔍 Search for apps
* 📂 Browse app categories
* ⭐ View ratings and reviews
* 📱 View app details and screenshots
* ⬇️ Download authorized APK files
* 📚 Manage downloaded apps
* 👤 Create and manage an account

Administrators will be able to manage apps, APK files, users, reviews, and download statistics.

## 🔐 Security

NR Store will prioritize secure application distribution.

Only **authorized and legally distributable APK files** should be uploaded to the platform.

The project should also implement:

* Firebase Authentication
* Admin authorization
* Firestore security rules
* Storage security rules
* Input validation
* File type validation
* Secure download URLs
